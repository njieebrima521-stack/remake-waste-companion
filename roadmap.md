# Roadmap — Collector experience

- [x] Import existing Remake project (resident app unchanged)
- [x] Collector sign-in with sample accounts (approved / suspended / awaiting / rejected)
- [x] Collector registration (type, contact, business name, registration no., areas, categories, vehicle, capacity, photo/logo); Remake Collector ID issued only after approval
- [x] Verification states + simulated Remake review; only approved accounts reach assignments
- [x] Role-specific dashboards and bottom navigation (recycling / private general-waste / independent)
- [x] Requests: category + area eligibility, accept / reject with reason / propose window, requester demo replies
- [x] Per-material minimum thresholds (admin demo screen); below-minimum requests stay as accumulation requests
- [x] Routing rules: residual waste to private companies first, independents as fallback; special waste never offered; mixed plastics marked "potentially recyclable"
- [x] Collection routes: suggested groupings (zone, day, partner, readiness, capacity), stops, arrival, confirm, missed, not ready, complete
- [x] QR scanner reused for collectors (valid / other collector / unassigned / collected / cancelled / invalid; no duplicates)
- [x] Material verification for recycling companies, separate from collection
- [x] History + performance charts, notifications, profile + edit (ID and status locked)
- [x] Tests for collector rules; resident app checked in the browser
